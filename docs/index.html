Junk filtered out

Storage boxes, dryers, spool holders, 3D pen refills, sample packs and tiny spools disappear.

Filters that stick

Material, brand and refill filters, synced across your Chrome devices.

Only when it matters

Switches on for filament searches only. Shopping for anything else, it does nothing.

Filters and dark mode

Install

Get it on the Chrome Web Store. Works in Chrome, Edge, Brave, and other Chromium browsers.

From source:

  1. Download the source zip and unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the extension folder.
  4. Search Amazon.com for filament.
